# Satellite tracking dependencies

- satellite.js 6.0.1: MIT; https://github.com/shashwatak/satellite-js
- geomagnetism 0.2.0: Apache-2.0; https://github.com/naturalatlas/geomagnetism
- WMM2025: NOAA/NCEI and British Geological Survey, https://www.ncei.noaa.gov/products/world-magnetic-model (2025.0–2030.0).

Rebuild local browser bundles with npm run vendor:tracking. No CDN is used at runtime.
