# iPhone 验收记录

状态：**待真机验证**。当前开发环境没有可操作的 iPhone，以下各项没有以桌面模拟结果代替。

请在实际 HTTPS 部署上，用至少一台 iOS 18.4+ iPhone 分别测试 Safari 和添加到主屏幕后的独立应用。

| 环境 | 记录 |
| --- | --- |
| iPhone 机型 | 待填写 |
| iOS 版本 | 待填写 |
| Safari / 主屏幕模式 | 两种均需验证 |
| 部署 URL 与资源版本 | 待填写 |
| 时间、地点与磁性配件 | 待填写 |

| 项目 | 步骤与验收标准 | 实测结果 |
| --- | --- | --- |
| 安装 | 共享 → 添加到主屏幕；桌面图标、名称和独立窗口正确 | 待测 |
| 定位允许／拒绝 | 定位成功显示位置；拒绝后可以手填且 SSTV 可用 | 待测 |
| 运动允许／拒绝 | 点击后请求权限；拒绝有说明；重新授权后能校准 | 待测 |
| 自动校准 | 首次启用显示引导，平放稳定约 2 秒后无需点击即可定向；重开、返回前台自动恢复，异常时提示平放；对照已知真北方位记录偏差 | 待测 |
| 顶部指向 | 抬高、降低、左右转动、横滚；方向提示符号正确 | 待测 |
| 横竖屏 | 指向轴始终为手机物理顶部；切换不出现 90° 错位 | 待测 |
| 天顶与跨北 | 359° → 0° 不跳转；接近天顶不出现误导性左右箭头 | 待测 |
| 传感器失效 | 磁干扰或数据暂停时撤去有效指向，不保留假实时数据 | 待测 |
| 前台并行 10 分钟 | 输入连续 SSTV 测试音频并开启跟踪，多次切换视图；记录音频连续性、界面响应、耗电和温升；到达原有上限正常保留录音 | 待测 |
| 自动结束帧提示 | 跟踪时收到完整图片，继续／停止接收操作正常 | 待测 |
| 常亮 | Safari 与桌面模式分别验证；系统拒绝时有提示 | 待测 |
| 锁屏／切后台 | 麦克风停止；返回后已采集音频可下载；重新接收需要主动点击 | 待测 |
| 离线 | 首次联网准备完成后开启飞行模式，重开应用；轨道缓存、过境、文件解码及编码可用 | 待测 |
| 星历更新 | 获取时间／历元可见；两小时内不重复请求；失败保留缓存 | 待测 |
| 应用升级 | 旧版接收期间新版等待；空闲时点击更新；其他窗口未关闭时禁止切换 | 待测 |
| 安全区域 | 刘海、灵动岛、底部手势区和横屏无关键控件遮挡 | 待测 |

自动验证：`npm run test:tracking` 对照 Vallado SGP4 与 NOAA WMM2025 参考值；`npm run test:pwa` 使用桌面 Chromium 测试同页接收、模拟姿态、缓存限流、离线 RX/TX 和原子更新。浏览器测试不能证明 iPhone 实际磁传感器精度或 10 分钟音频稳定性。
