自动验证：`npm run test:tracking` 对照 Vallado SGP4 与 NOAA WMM2025 参考值，并验证目录独立限流、失败缓存、搜索与收藏；`npm run test:pwa` 使用桌面 Chromium 测试同页接收、模拟姿态、目录交互、音频流／画布连续性、缓存限流、旧数据库兼容、离线 RX/TX 和原子更新。新增目录项目仍待 iPhone 真机验证，桌面结果不能证明 iPhone 软键盘行为、实际磁传感器精度或 10 分钟音频稳定性。

多普勒定向验证：`npm run test:doppler` 检查频移符号、地球自转、距离差分和频率管理；`npm run test:field` 检查手机同屏、音频／画布连续性、自定义频率、离线和前后台恢复；完整回归使用 `npm test`。
